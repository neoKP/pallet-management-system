ระบบถูกออกแบบมาเพื่อรองรับเงื่อนไขทางธุรกิจที่ซับซ้อนและรวมศูนย์การจัดการ:

| ฟีเจอร์หลัก | รายละเอียด |
| ------------- | ----------- |
| **Lascam Tiered Rental** | อัตรา 1.40 (1k-2k), 1.19 (2k-3k), 1.12 (3k+) คิดจากยอดค้าง Neo Corp vs Loscam วังน้อย |
| **Sino Grace Period** | ฟรี 10 วันแรก หากเกินกำหนดคิดค่าเช่า 1.00 บาท/วัน/ใบ |
| **Centralized Return** | ควบคุมระเบียบการคืนพาเลท (OUT) ให้รวมศูนย์ที่สาขานครสวรรค์เท่านั้น |
| **Quick Loop 2.1.0** | ระบบบันทึกด่วนที่รองรับข้อมูลรถ เลขที่ ECD และคัดกรองคู่ค้าตามสาขา |

## 4. สาขาและคู่ค้า (Business Rules)

### 🤝 เงื่อนไขสำคัญของคู่ค้ากองกลาง

#### 1. บ. นีโอ คอร์ปอเรท (Lascam / Neo Corp)

- **ประเภทพาเลท**: เฉพาะสีแดง (Loscam Red) 🔴
- **การรับเข้า (IN)**: รับจาก **"บ. นีโอ คอร์ปอเรท"** (ต้นทางหลัก)
- **การจ่ายออก (OUT)**: คืนที่ **"Loscam วังน้อย"**
- **การคิดค่าเช่า**: คิดจากยอดค้างสะสม (รับจาก Neo - คืน Wangnoi) ตามเรท:
  - 1,000 - 2,000 ใบ: **1.40 บาท/วัน**
  - 2,001 - 3,000 ใบ: **1.19 บาท/วัน** (ลด 15%)
  - 3,001 ใบขึ้นไป: **1.12 บาท/วัน** (ลด 20%)

#### 2. บ. ซีโน-แปซิฟิค (Sino)

- **ประเภทพาเลท**: **พาเลทแดง (Red) 🔴** และ **พาเลทฟ้า (Blue) 🔵**
- **เงื่อนไขเวลา**: ต้องคืนภายใน **10 วัน** นับจากวันที่ยืม
- **ค่าเช่าส่วนเกิน**: หากเกิน 10 วัน ซีโน่จะคิดค่าเช่า **1.00 บาท/วัน/ใบ**
- **การจ่ายออก (OUT)**: **ทำได้เฉพาะสาขานครสวรรค์ (Hub NW) เท่านั้น**

## 5. ระบบงานพิเศษ (Quick Loop)

### 🏎️ Quick Loop (แยกตามสาขา)

ระบบจะกรองปุ่มคู่ค้าเพื่อให้บันทึกได้รวดเร็วตามหน้างานแต่ละที่:

- **สาขาพุทธมณฑลสาย 3**:
  - [IN/OUT] Lamsoon, UFC, Loxley, Kopee, HI-Q
- **สาขานครสวรรค์ (Hub NW)**:
  - [IN/OUT] **Sino**
  - [IN Only] **Neo Corp**
  - [OUT Only] **Loscam วังน้อย** (สำหรับการคืนพาเลทกองกลาง)

## 6. SOP - การรับพาเลทเข้า (IN)

### 📝 ขั้นตอนการปฏิบัติงาน (IN)

1. พนักงานตรวจสอบพาเลทหน้างานจริง (สีแดง/เหลือง/ส้ม/พลาสติก)
2. เข้าเมนู **Record Movement** ➔ เลือกประเภท **IN (รับเข้า)**
3. เลือกแหล่งที่มา (เช่น รับจาก Neo Corp หรือ รับจากการโอนย้าย)
4. ระบุจำนวน และ **เลขที่อ้างอิง (ECD)** ให้ตรงกับใบส่งของ
5. บันทึกข้อมูลรถและชื่อคนขับเพื่อใช้ในการตรวจสอบภายหลัง
6. กด **Save** ➔ ยอดสต็อกจะเพิ่มขึ้นทันที

---

## 7. SOP - การจ่ายพาเลทออก (OUT)

### 📝 ขั้นตอนการปฏิบัติงาน (OUT)

1. **ตรวจสอบสิทธิ์**: หากเป็นการคืนพาเลทให้ Sino หรือ Lascam (วังน้อย) **ต้องทำที่สาขานครสวรรค์เท่านั้น**
2. เลือกประเภท **OUT (จ่ายออก)**
3. เลือกปลายทางที่จะส่งคืน
4. ระบุจำนวนพาเลทที่ส่งออกจริง
5. บันทึกข้อมูลการขนส่งให้ครบถ้วน ➔ กด **Save**

---

## 8. SOP - การจัดการยอดเริ่มต้นและสต็อก (Admin)

สิทธิ์เฉพาะ Admin (ยืนยันด้วยรหัสผ่านบัญชี admin ที่ล็อกอินอยู่):

1. ไปที่ **Settings** ➔ **Admin Control**
2. ใช้สำหรับตั้งยอดเริ่มต้น (Initial) หรือปรับปรุงสต็อก (Adjust) กรณีตรวจนับจริงไม่ตรงกับระบบ

## 9. การใช้งาน Dashboard & Analytics (Premium Edition)

ระบบใหม่ได้รับการอัปเกรดเพื่อการวิเคราะห์ข้อมูลระดับสูง (High-Fidelity):

### 🏢 มุมมองการบริหารจัดการ (Management View)

- **Centralized Return Tracking**: ตรวจสอบการคืนพาเลทกองกลาง (Sino/Neo Corp) ว่ารวมศูนย์ที่ Hub NW จริงหรือไม่
- **Sino Aging Status (10-Day Grace Period)**: กราฟแสดงเขตอันตราย (Overdue) สำหรับพาเลท Sino ที่ค้างคืนเกิน 10 วัน
- **Logistic Insight**: วิเคราะห์ประเภทรถที่วิ่งเข้า-ออก (4 ล้อ, 10 ล้อ, เทรลเลอร์) เพื่อจัดการพื้นที่

### ⚡ มุมมองปฏิบัติการสาขา (Operational View)

- **Sai 3 Performance**: ติดตามความเร็ว (Velocity) ของพาร์ทเนอร์รายวัน เช่น ล่ำสูง, UFC, Loxley
- **Hygiene Stock Check**: ตรวจสอบความสมดุลของสีพาเลทในสาขา (เช่น สต็อกสีฟ้าสำหรับ UFC เพียงพอไหม?)
- **Quick Loop Efficiency**: เปรียบเทียบรายการที่ลงผ่านปุ่มด่วนเทียบกับปกติ เพื่อวัดความไวในการทำงาน
- **Peak Activities**: กราฟวิเคราะห์ชั่วโมงการทำงานหนาแน่นของแต่ละสาขา
